# 前端学习练习 (front-end-practice)

这是我在学习前端基础（HTML / CSS）过程中的练习代码仓库，都是一些可以直接用浏览器打开的小页面。

## 内容一览

| 文件 | 说明 |
|---|---|
| `常见文本标签.html` | 文本标签练习：标题（h1~h6）、段落、粗体/斜体/下划线/删除线、无序/有序列表 |
| `HTML区块.html` | 块级布局练习：div 导航栏与内容区、超链接（普通/新窗口打开） |
| `HTML属性.html` | 属性练习：href、target、img（含本地引用失效演示）、br、hr |
| `HTML表单.html` | 表单练习：文本输入、密码框、单选、复选、提交按钮 |
| `CSS导入方式.html` | CSS 入门：内联样式与内部样式表的对比 |
| `课后练习.html` | 自主练习：图片插入、链接跳转、标题与分隔线 |
| `screenshots/` | 练习中用到的图标素材（bard、bing、chatgpt 等 AI 工具 SVG 图标） |

## 运行方式

用浏览器直接打开 `.html` 文件即可，无需任何环境：

```bash
start HTML表单.html
```

（在文件资源管理器里双击打开也行）

## 说明

本仓库为个人前端基础学习用途，内容涵盖 HTML 常见标签、属性、表单与 CSS 基础，代码仅供学习参考。
